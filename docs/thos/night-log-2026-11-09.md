## Tools added for debugging (keep them)

* `thostrace PID|-c NAME [off]` — logs every system call (entry and exit lines) of a process and its future children to the kernel log (netconsole!).
* `thosshot`, `tools/thos-shot.sh` — screenshots (the framebuffer is 1366x768, stride 5504 B on the Acer; the Acer pushes the gzipped framebuffer by `nc` to the host, SSH itself only moves ~7 KB/s).
* `thosinput move|click|drag|scroll|key|type` — remote control. `type` assumes the German layout.
* `sigmimic`, `dropbear-mimic-test`, `ssh-exit-test`, `screenshot-test`, `input-inject-test` — regression tests for the above.
